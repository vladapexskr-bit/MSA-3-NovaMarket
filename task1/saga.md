# Часть 2. Проектирование Saga для оформления заказа

Реестр событий Saga-хореографии

В таблице представлены все события, которые участвуют в процессе оформления заказа, включая успешные этапы, ошибки и компенсационные действия.

| Этап | Тип события | Название |
| :--- | :--- | :--- |
| **Создание заказа** | domain | `OrderCreated` |
| **Резервирование товара** | domain | `StockReserved` |
| **Ошибка резервирования (нет товара)** | failure | `StockReservationFailed` |
| **Отмена заказа (из-за нехватки)** | compensation | `OrderCancelled` |
| **Успешная оплата** | domain | `PaymentSucceeded` |
| **Ошибка оплаты (нет денег/отказ банка)** | failure | `PaymentFailed` |
| **Возврат товара на склад (если оплата упала)** | compensation | `StockReleased` |
| **Создание заявки на доставку** | domain | `DeliveryCreated` |
| **Уведомление покупателя** | domain | `NotificationSent` |
